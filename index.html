Fundamentos

Antes de escrever a primeira consulta, entenda o essencial: o que é SQL e como uma consulta é montada.

O que é SQL?

SQL (Structured Query Language) é a linguagem usada para conversar com bancos de dados relacionais — pedir informações, filtrar, cruzar tabelas e atualizar registros. É a ferramenta que transforma uma pergunta de negócio em uma resposta concreta, direto na fonte dos dados.

Para que serve?

  • Consultar dados
  • Filtrar informações
  • Criar relatórios
  • Analisar indicadores
  • Cruzar tabelas
  • Atualizar dados
  • Criar estruturas

🔎 SELECT

O comando mais usado do SQL: escolhe quais colunas você quer ver no resultado.

Sintaxe

select.sql
SELECT coluna
FROM tabela;

Exemplo

clientes.sql
SELECT nome, email
FROM clientes;

O que acontece? O banco procura a tabela clientes e devolve apenas as colunas nome e email de todas as linhas — nada mais.

🎯 WHERE

Filtra quais linhas entram no resultado. Sem WHERE, o SQL devolve tudo.

Sintaxe

where.sql
SELECT coluna
FROM tabela
WHERE condição;

Exemplo

fortaleza.sql
SELECT *
FROM clientes
WHERE cidade = 'Fortaleza';

Mais condições comuns

condicoes.sql
WHERE idade > 18
WHERE salario >= 3000
WHERE status = 'Ativo'
WHERE cidade <> 'Recife'

Operadores

🔗 JOINs

JOINs combinam linhas de duas tabelas a partir de uma coluna em comum — a base de praticamente toda análise cruzada.

clientes
vendas

INNER JOIN

Retorna apenas os registros que possuem correspondência nas duas tabelas.

inner.sql
SELECT *
FROM clientes c
INNER JOIN vendas v
    ON c.id = v.cliente_id;

LEFT JOIN

Traz todos os registros da tabela da esquerda, com os dados da direita quando existirem — senão, vem NULL.

left.sql
SELECT *
FROM clientes c
LEFT JOIN vendas v
    ON c.id = v.cliente_id;

RIGHT JOIN

O espelho do LEFT JOIN: traz tudo da tabela da direita, com correspondência da esquerda quando houver.

right.sql
SELECT *
FROM clientes c
RIGHT JOIN vendas v
    ON c.id = v.cliente_id;

FULL OUTER JOIN

Traz tudo das duas tabelas, com NULL onde não houver correspondência de nenhum dos lados.

full.sql
SELECT *
FROM clientes c
FULL OUTER JOIN vendas v
    ON c.id = v.cliente_id;

📊 GROUP BY

Agrupa linhas que compartilham um valor, para calcular algo por grupo — contagem, soma, média.

Sintaxe

groupby.sql
SELECT coluna, COUNT(*)
FROM tabela
GROUP BY coluna;

Exemplo

cidades.sql
SELECT cidade, COUNT(*) AS quantidade
FROM clientes
GROUP BY cidade;

Regra de ouro: toda coluna no SELECT que não está dentro de uma função de agregação precisa estar no GROUP BY.

CASE WHEN — o IF do SQL

case.sql
CASE
    WHEN condição THEN resultado
    ELSE resultado
END
faixa_salarial.sql
SELECT
    nome,
    salario,
    CASE
        WHEN salario >= 5000 THEN 'Alto'
        WHEN salario >= 3000 THEN 'Médio'
        ELSE 'Baixo'
    END AS faixa_salarial
FROM funcionarios;

From zero to query ✨

Um banco fictício com duas tabelas — clientes e vendas — para evoluir consulta por consulta.

clientes
  • id
  • nome
  • cidade
  • idade
vendas
  • id
  • cliente_id
  • produto
  • valor
  • data_venda
Nível 1
nivel1.sql
SELECT *
FROM clientes;
Nível 2
nivel2.sql
SELECT nome, cidade
FROM clientes
WHERE cidade = 'Fortaleza';
Nível 3
nivel3.sql
SELECT cidade, COUNT(*) AS clientes
FROM clientes
GROUP BY cidade;
Nível 4
nivel4.sql
SELECT
    c.nome,
    SUM(v.valor) AS total_compras
FROM clientes c
INNER JOIN vendas v
    ON c.id = v.cliente_id
GROUP BY c.nome
ORDER BY total_compras DESC;
